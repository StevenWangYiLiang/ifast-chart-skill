# 验收

## 数据和结构

运行 `python scripts/verify.py <output-directory>`，检查产物哈希、数值缓存、图表数量、工作表数量、本页数据引用、无外部链接、年度日期轴、零基线、4–7 个纵轴标签及 SVG 厘米尺寸。

同时抽查原始输入与整理后数据：来源、截止日、统计频率、原始单位、百分比是小数还是百分点、缺失值、排序和月份对齐。生成器不负责鉴别输入真实性。

生成时根据数据计算轴范围和步长。修改 Excel 数据可更新曲线，但超出当前范围、量级变化或新增行后，需要重新生成图表；没有内置 VBA 或三格式自动同步服务。

## 显示效果

至少打开 HTML 和每种图型/尺寸的一张独立 SVG，检查实际字体、字体大小、标题、图例、轴单位和刻度线。多图或版式不同的情况应扩大到每张。

- 图表外框是指定厘米尺寸；不要通过缩放整张图造成字体变小。
- 标题加粗 12 磅，正文通常 9 磅。确认实际使用 HarmonyOS Sans SC，而不是仅检查 CSS 字体声明。字体文件不随包分发。
- 图例底部居中，与系列数量、颜色、线型一致；无截断或遮盖。
- 每年 1 月 1 日有实际刻度线；小号可用两位年份。
- 每个纵轴包含 0，4–7 个标签；单位置顶、横排、与刻度同色。左右轴含义清楚。
- 大数值只按万/百万/亿/万亿缩放显示，原始绘图数据不变。示例：220000 点显示为 22 万点。
- 堆积图合计和标签正确；缺失值不绘制成 0；负收益方向正确。
- 标题、图例、刻度、单位、来源无裁切，无重叠。

## Excel 实机

Windows 有 Excel 时运行 `polish-excel.ps1`，然后检查导出的 `*-excel.png`。脚本使用本机 Excel 原生对象调整位置，不安装 Office、不嵌入字体、不改变源数据。

原生图表应引用本页绘图单元格。临时修改一个值，确认曲线/柱形更新，随后恢复；不要把静态图片误当成原生图表。小数步长必须保留足够小数位，避免 2.5% 被显示成 3%。

没有目标应用时，仅报告结构验收和已完成的网页/SVG 检查；不要把它们升级为 Excel 实机显示通过。便携导出与 Excel 校准使用不同布局机制，不能承诺所有 Office 版本像素一致。
